Anomaly Detection

Strømmende ML-pipeline for sanntidsdeteksjon av mistenkelige finanstransaksjoner. Data flyter fra Kafka gjennom en Isolation Forest-modell til PostgreSQL, med live evalueringsmetrikker visualisert i Streamlit. Fullt Dockerisert.

Teknologi: Apache Kafka, Zookeeper, Python, scikit-learn, PostgreSQL, Streamlit, Plotly, Docker, docker-compose, psycopg2, pandas, numpy

Nettside som henter sanntidsdata fra Nordpool og spår strømprisene time for time de neste 24 timene. Brukeren kan velge prisområde og se visuell priskurve for dagen.

Teknologi: FastAPI, Python, PostgreSQL, SQLAlchemy, XGBoost, scikit-learn, psycopg2, python-dotenv, Render, Neon, React, Vite, Recharts, Axios, React Router, Vercel
